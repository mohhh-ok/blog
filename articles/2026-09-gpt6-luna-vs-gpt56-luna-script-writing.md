OpenAI の軽量モデル gpt-6-luna が出ました。単価は gpt-5.6-luna の約半分です。一方で、SNS で見かけたコーディングエージェントのリーダーボードでは、gpt-6-luna の正答率が gpt-5.6-luna より低く出ていました。

https://x.com/gosrum/status/2102549735039283626

安くなったけど頭は悪くなったのか。自分の用途で確かめるために、動画編集アプリに組み込んでいる AI エージェントで、両方に同じ指示を出して台本を書かせました。

## 結論

- 台本の文章は gpt-6-luna の方が明らかに良かったです。gpt-5.6-luna はありふれたブログの文章っぽく、gpt-6-luna はちゃんとした企業の文章っぽく読めます
- エディタへの編集命令（JSON）の正しさは、今回の範囲では差が出ませんでした。本計測ではどちらも 15 回すべて適用できています
- 代わりに gpt-6-luna は遅くなります。応答の中央値は 5.4 秒から 7.4 秒、最長は 8.4 秒から 14.0 秒になりました
- 1 回の原価はほぼ同じです。gpt-6-luna は出力トークンが倍以上に増えますが、単価の安さで相殺されます

コーディングのベンチで負けていても、人に聞かせる文章を書く用途なら gpt-6-luna を選ぶ価値があります。

## 比べた条件

エージェントは、ユーザーの話した内容から台本を書き、エディタの状態を書き換える編集命令のリストを JSON で返します。1 回の指示につき LLM を 1 回呼ぶだけで、ループは回しません。

- gpt-5.6-luna: reasoning effort は low（本番と同じ）
- gpt-6-luna: reasoning effort は指定しない（API の既定）

gpt-6-luna の effort を既定にしたのは、別のアプリで effort を下げたときに表記のルールが崩れたからです。gpt-6-luna は effort を下げない前提で比べています。

指示は 5 種類で、それぞれ 3 回ずつ、合計 30 回投げました。

1. 商品紹介を話し言葉のまま一気にしゃべった 337 字の発話から、台本を起こす
2. 「バスケットボールの告知」の一言だけ
3. 社内向けに、経費精算システムの切り替えを 30 秒で案内する
4. 2 人の掛け合い（店員と客）で、カフェの春限定「桜ラテ」を 40 秒で紹介する
5. 硬い既存の台本を、親しみやすい話し言葉に直す

秒数を指定したのは 3 と 4 だけです。プロンプトには話す速さの目安（1 秒あたりの文字数）を渡し、「発話に秒数があればそれに従い、無ければ内容から判断する」と書いています。1・2・5 の長さはモデルに任せた結果です。

## 実際の台本

指示ごとに、3 回のうち 1 回目の出力を代表として載せます。左が gpt-5.6-luna、右が gpt-6-luna です。台本の文はモデルの出力のままで、手を入れていません。推定秒数は文字数から出した目安です。

## 数字

本計測の 3 周、各モデル 15 回の集計です。

| | gpt-5.6-luna (low) | gpt-6-luna (既定) |
|---|---|---|
| 編集命令がエディタに適用できた | 15/15 | 15/15 |
| 応答時間の中央値 | 5.4 秒 | 7.4 秒 |
| 応答時間の最長 | 8.4 秒 | 14.0 秒 |
| 出力トークンの平均 | 392 | 847 |
| うち推論トークン | 50 | 489 |
| 1 回の原価の平均 | $0.00055 | $0.00047 |

台本の長さは、指示ごとに次のとおりです。推定秒数は台本の文字数から出した目安で、3 回分を並べています。

| 指示 | 秒数の指定 | gpt-5.6-luna | gpt-6-luna |
|---|---|---|---|
| 1. 自由発話からの台本化 | なし | 52 / 54 / 46 秒 | 33 / 35 / 38 秒 |
| 2. バスケットボールの告知 | なし | 15 / 14 / 17 秒 | 17 / 16 / 23 秒 |
| 3. 経費精算システムの案内 | 30 秒 | 36 / 31 / 33 秒 | 29 / 31 / 31 秒 |
| 4. 桜ラテの掛け合い | 40 秒 | 46 / 38 / 35 秒 | 49 / 42 / 43 秒 |
| 5. 硬い台本の書き直し | なし | 20 / 21 / 20 秒 | 20 / 19 / 19 秒 |

秒数を指定した 3 と 4 では、gpt-6-luna の方が 3 回のぶれが小さく出ました。3 は 29〜31 秒で指定の 30 秒にほぼ収まり、4 は 42〜49 秒で 3 回とも指定の 40 秒を超えています。gpt-5.6-luna は 3 が 31〜36 秒、4 が 35〜46 秒で、指定の上下どちらにも外れました。

単価は公式の料金ページ（2026-09-23 時点、100 万トークンあたり）で、gpt-5.6-luna が input $0.20 / output $1.20、gpt-6-luna が input $0.10 / output $0.50 です。

本計測の前に動作確認で 1 周だけ流した回では、両方に失敗が出ています。gpt-5.6-luna は 1 回、返事では「3 幕に分けました」と言いながら編集命令を出しませんでした。gpt-6-luna は 2 回で、1 回は同じく編集命令を出さず、もう 1 回は話し手のいない幕にセリフを入れて弾かれました。5 回中の 1〜2 回なので、失敗しやすさの差を言える量ではありません。どちらを使う場合でも、編集命令が出なかったときと弾かれたときの扱いは必要です。

## 使い分け

- 人に読ませる・聞かせる文章が出力の中心なら、gpt-6-luna を試す価値があります。effort は下げずに使います
- 応答の速さが体験を左右する場面では、中央値で 2 秒、最長で 6 秒ほど遅くなるのを受け入れられるかを先に決めます
- 判定や分類のように文章の良さが効かない用途は、gpt-5.6-luna のままで困りません

ベンチの順位は、自分の用途に近い課題で測るまでは参考にとどめるのがよさそうです。今回は 30 回、API 料金は数セントで判断できました。
